loom::unique_tuple< Ts >::unique_tuple ( Args &&... args)
inlineconstexprnoexcept

Constructs all the containing objects in place from args.

By default, each containing object is constructed from the corresponding argument.

Pass loom::uniform_init as the first argument to indicate that all the containing elements should be constructed from the same remaining arguments.

Pass std::piecewise_construct as the first argument or after loom::uniform_init to indicate that the provided arguments are tuples and should be unpacked for constructing corresponding objects, i. e. uses std::make_from_tuple to construct the objects.
