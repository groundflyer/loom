Detailed Description

template<typename T, unsigned NC, typename Allocator = std::allocator<T>>
class loom::ScanlineImage< T, NC, Allocator >

Multi-channel raster image.

Template Parameters
Tchannel value type.
NCnumber of channels.

Classes specialized from this template satisfy std::ranges::random_access_range and std::ranges::sized_range.

When iterating over an image value type is a pair of pixel coordinates and a view to the pixel.

For example:

for (auto [pos, pix]: img)
{
const auto [px, py] = pos;
pix = compute_new_pixel_value(px, py);
}
