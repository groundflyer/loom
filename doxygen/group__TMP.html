Detailed Description

Template metaprogramming.

Here we define metafunctions as class templates, where function parameters are template parameters and the result is a public typedef member type or a static constexpr member value.

The templates are hidden in the detail namespace, while type aliases and variable templates are visible in loom namespace.

Typedef Documentation

◆ fst_t

template<typename Pair>
using loom::fst_t = fst<Pair>::type

Extract the first type of Pair.

It is basically the same as typelist::head, but ensures that the number of elements in type_sequence Pair is exactly two.

◆ snd_t

template<typename Pair>
using loom::snd_t = snd<Pair>::type

Extract the second type of Pair.

Same as typelist::last, but guarantees that type_sequence Pair consists only of two types.
