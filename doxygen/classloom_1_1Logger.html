Detailed Description

Simple logger with classic verbosity schema, timestamps and colorful output.

Uses fmt to format messages.

Prints only into stdout and stderr.

Member Enumeration Documentation

◆ Level

enum loom::Logger::Level

Indicates what kind of messages should be printed.

The lower the level the more messages will be printed. For instance, if level is WARNING, only warnings, errors and critical errors will be printed.

Enumerator

all kind of messages
