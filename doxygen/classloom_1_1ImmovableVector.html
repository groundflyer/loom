Detailed Description

template<typename T, typename Allocator = std::allocator<T>>
class loom::ImmovableVector< T, Allocator >

Dynamic size container for non copy/move-constructible objects.

ImmovableVector is capable of holding objects that aren't default-constructible, copy-constructible, move-constructible, copy-assignable, move-assignable. As a result it is not resizeable, copyable or moveable itself.

Containing objects are constructed and initialized in-place only once, in the constructor.
