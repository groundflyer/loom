Computes ranges of chunks containing equal values saving them to bgns and ends.

Parameters
bgnscontains ranges' starts, the index of the first range element in pcs.
endscontains ranges' ends, the index after the last range element in pcs.
Nsize of bgns and ends.
pcsprogram counters.
pcs_sizesize of pcs.
Template Parameters
pc_tprogram counter type.

Basically parallel version of groupby / chunkby(==) with known number of chunks which is \(N = C + 1\) where C is number of blocks. The last range is for terminated blocks.

The beginning of the first and end of the last ranges are no set here.
