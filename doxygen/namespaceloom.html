Enumeration Type Documentation

◆ AFFINITY

enum class loom::AFFINITY
strong

Threadpool affinity method.

Extra threads (if threadpool size exceeds the number of CPUs) never affined.

Physical affinity example: The topology of a SMT2 CPU with 4 physical cores and 8 logical cores is [[0, 4], [1, 5], [2, 6], [3, 7]]. First physical core provides two logical cores indexed 0 and 4, second - 1 and 5, etc. Correspondingly first thread is affined to logical cores 0 and 4, second - to 1 and 5, etc.

Enumerator
NONE 

Don't affine threads.

FULL 

Affine every thread to a separate logical core.

PHYSICAL 

Affine every thread to logical siblings of each physical core.
