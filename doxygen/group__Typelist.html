◆ materialize_with()

template<typename Ret, typename F, typename... Ts, typename... Args>
Ret loom::typelist::materialize_with ( type_sequence< Ts... > ,
F && f,
Args &&... args )
constexprnoexcept

Consecutively invoke f with each class of list as the first template parameter and args as function parameters and put results into an instance of Ret. It's similar to std::transform or loom::map_tuple, except the input is a list of types, so it can be seen as transformation of virtual entities (types) to actual values.

Each invocation looks roughly like this:

auto v_n = f<T_n>(args...);
