Make standard parametric test.

Parameters
gtest data generator. If t accepts few parameters must return std::pair or std::tuple.
ttesting function.
vvalidation function.

The check process is following:

  1. Generate test data with g.
  2. Invoke test t with the data.
  3. Validate test results by invoking v with the data and the result of test invocation deciding if check was successful.

To pass requires all runs to succeed.
