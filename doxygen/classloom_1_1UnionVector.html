Detailed Description

template<typename Types, typename Allocator = std::allocator<std::byte>>
requires (typelist::all<std::is_default_constructible, Types>)
class loom::UnionVector< Types, Allocator >

Unsafe union of vectors.

UnionVector holds a contigous memory segment and provides a typed view to it.

Only one type can be accessed at a time as the segment isn't aligned to common size.

When the integrated Types have the same size the operator[] is available.

The number of elements of each type in type_sequence Types is always equal and accesible via count().
