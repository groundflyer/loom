Detailed Description

template<std::size_t N>
class loom::thread_pool< N >

Constant sized thread pool.

Template Parameters
Nnumber of threads.

By default, threads join synchronously upon thread pool destruction, thus the current scope might be blocked until all threads complete their tasks. To avoid this behavior use detach().
